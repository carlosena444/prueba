Descripción del proyecto
Este proyecto consistió en la creación de una API REST para la gestión de tareas personales con Node.js, Express y TypeScript. Permite registrar usuarios, iniciar sesión y administrar tareas con autenticación JWT, validación de entradas y control de acceso por usuario.

Durante el desarrollo, utilicé herramientas de IA como apoyo para estructurar ideas, revisar conceptos de arquitectura y acelerar la implementación inicial. Sin embargo, la validación, la corrección de errores y la toma de decisiones finales fueron realizadas por mí, asegurando que entendiera y pudiera justificar cada parte de la solución.
